## Caveats

**(a) grill-screen "grill_me" capture-timing artifact.** Under Playwright's
fresh browser context the word `grill_me` and the GRILLING caption can
briefly appear in the captured frame before the early-return full-bleed
`GrillScreen` fully settles. The live, settled DOM is clean (verified
directly; the diagram is fully replaced). This was chased for >2 cycles —
a `ContentPanel` guard was tried twice with no effect and reverted both
times (honest: no-op changes are not shipped). Concluded to be a
Playwright fresh-context/timing artifact, documented, and bypassed per the
no-thrash discipline. Not a user-facing defect.

**(b) Mobile (390px) chrome density.** At the 390-wide viewport the bottom
chrome (voice state, Mic/Back/Pause/Skip, quick-chips) is dense but
functional and non-overlapping. Acceptable; flagged for a future
mobile-specific pass, out of this polish scope.
